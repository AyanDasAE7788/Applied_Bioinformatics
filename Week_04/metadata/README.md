# SRA Metadata

The SRA Run Selector metadata used for this analysis was downloaded as
`SraRunTable.csv` from NCBI SRA after searching for:

`"Escherichia coli str. K-12 substr. MG1655"[Organism]`

The metadata were downloaded on September 19, 2026.

The full metadata table is not stored in this repository because it is a
downloaded 14 MB file. The summarized results are reported in the main
`README.md`.
